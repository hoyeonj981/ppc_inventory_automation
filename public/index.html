🦉 Owl-bot

Slack에서 과재고·부족재고를 보고하면 Google Sheets에 자동으로 기록하는 도구입니다.

사용 전 확인 /r · /report로 보고 🦉 반응으로 저장 시트 기록 항목 문제 해결 업데이트 내역

두 가지 방법으로 기록합니다

  1. /r 또는 /report — 새로 발견한 재고를 앱 입력 창으로 보고하고 Google Sheets에 저장합니다.
  2. 🦉 :owl: 반응 — 사람이 직접 작성한 기존 재고 보고 메시지를 Google Sheets에 저장합니다.

사용 전 확인

  • Owl-bot이 사용할 Slack 채널에 초대되어 있어야 합니다.
  • 관리자가 Google Sheets 연결을 완료해 두어야 합니다.

기능 1 · /r 또는 /report로 보고하기

  1. 실사 중 재고 보고가 필요하면 PDA에 설치된 Slack 앱을 실행합니다.
  2. 보고할 채널에서 /r 또는 /report를 입력합니다.

    보고 메시지는 명령어를 실행한 채널에 게시되므로 반드시 실제로 보고할 채널에서 실행해 주세요.

  3. 입력 창에 재고 정보를 입력합니다.
항목입력 방법
사진선택 사항. 촬영하거나 JPG/JPEG/PNG/GIF 1장 첨부
바코드최대 100자, 앞자리 0 유지, PDA 바코드 스캔 가능
발견로케이션예: A01-01-101, 최대 100자, PDA 바코드 스캔 가능
유형과재고 또는 부족재고
소비기한(제조기한)날짜 선택, 이미 지난 날짜도 입력 가능
수량1 이상의 정수
발견자현재 채널 멤버 중에서 선택
  1. 저장을 누르면 입력값을 확인합니다. 문제가 있으면 해당 항목에 오류가 표시됩니다.
  2. 정상적으로 제출되면 아래 순서로 처리됩니다. 처리 중에 창을 닫아도 처리는 계속됩니다.

    Slack 보고 게시 → Google Sheets 기록 → 저장 완료

  3. 저장된 기록을 확인합니다.
    • Slack: 채널에 게시된 보고 메시지를 확인합니다.
    • Google Sheets: 한 행이 추가됩니다. 사진은 시트에 직접 저장되지 않고 Slack 메시지에 보관됩니다.
    • 시트의 보고 메시지 링크로 보고 내용과 사진을 볼 수 있습니다. 해당 Slack 채널에 접근할 권한이 필요합니다.

기능 2 · 🦉 반응으로 기존 보고 메시지 저장

사람이 직접 작성한 재고 보고 메시지도 Google Sheets에 저장할 수 있습니다. 과거 메시지도 가능합니다.

  1. 저장하려는 메시지에 🦉 :owl: 반응을 추가합니다.
  2. Owl-bot이 메시지를 읽어 필요한 정보를 확인합니다. 메시지는 아래 형식을 따라야 합니다. 
    과재고 발생 보고
• 발견 크루명: 김배민
• 발견일시/위치: 9월 24일 /A11-11-203
• SKU명: 롯데 찰옥수수 140ml
• 바코드: 8801234567890
• 소비기한: 2026-12-31
• 과재고 1개
    • 첫 줄은 과재고 발생 보고 또는 부족재고 발생 보고로 적습니다.
    • 수량은 필수입니다. 과재고 1개, 부족재고 1개 또는 수량: 1로 적어 주세요.
    • 위치는 필수입니다. 발견일시/위치 대신 발견로케이션: A11-11-203로 적어도 됩니다.
    • 바코드·SKU명·소비기한이 없으면 시트에 N/A로 기록됩니다. 소비기한은 연도까지 적어 주세요.
    • 발견 크루명이 없으면 메시지 작성자의 이름으로 기록됩니다.
    • 한 메시지에 한 건만 저장됩니다.
  3. 정상적으로 저장되면 Owl-bot이 원본 메시지에 ✅ 반응을 추가합니다. Owl-bot의 ✅가 이미 있는 메시지는 다시 저장하지 않습니다.
  4. 처리 결과는 🦉 반응을 추가한 사람에게만 표시됩니다.

Google Sheets에 기록되는 항목

두 방법 모두 같은 시트에 아래 순서로 한 행씩 추가됩니다.

열항목
A바코드
BSKU명 (🦉 반응으로 저장할 때만)
C수량
D소비기한(제조기한)
E발견로케이션
F발견자
G발견시각 (한국시간)
H유형
I입력경로 (앱 입력 / 메시지 변환)
J보고 메시지 링크

입력 방법에 따라 없는 값은 빈칸 대신 N/A로 기록됩니다.

문제가 발생한 경우

입력 화면이 열리지 않음
잠시 후 다시 시도해 주세요. 계속 실패하면 관리자에게 앱의 채널 초대 여부와 권한 확인을 요청해 주세요.
발견자가 목록에 없음
해당 사용자가 현재 Slack 채널에 참여 중인지 확인해 주세요.
"저장 확인 필요"가 표시됨
바로 다시 제출하지 말고 Slack 채널과 Google Sheets에 실제 기록이 생성됐는지 먼저 확인해 주세요.
Slack에는 보고가 있지만 시트에는 없음
관리자에게 확인을 요청해 주세요. 다시 제출하면 Slack 보고가 중복될 수 있습니다.
🦉를 추가했지만 저장되지 않음
Owl-bot이 안내한 누락·오류 내용을 확인해 메시지를 수정한 뒤, 🦉를 지웠다가 다시 추가해 주세요.
🦉 저장 여부를 확인하지 못함
Google Sheets를 먼저 확인하고, 실제 기록이 없을 때만 다시 시도해 주세요.
